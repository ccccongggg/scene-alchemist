# 场景炼金师 · 星辰图（一帖千面）— 原型

> 本目录是「场景炼金师」项目的**最早原型**，源自原仓库 `scenario-alchemist`（纯静态单文件 `index.html`）。
> 主应用（`frontend/` + `backend/`）的「星图 / 同帖千面」可视化即由此原型演化而来，本目录保留作为起源参考。

知乎好帖 → 真实场景迁移可视化原型。一颗「原帖太阳」居中，外圈每颗「星」都是一个真实读者的处境。

## 这是什么

把一篇高赞知乎好帖，重绘成一张「星辰图」：

- **太阳** = 原帖（被验证过的起点）
- **星点** = 真实读者把原帖搬到自己处境后产生的变体
  - 星越大 → 处境相似的人越多
  - 亮星 = 已验证 / 暗星 = 待验证
  - 颜色 = 迁移深度（绿=小改参数 / 金=动结构 / 红=换方案）

## 交互

- **单击星点**：视角拉近到该星，右侧显示该处境的四大板块——
  ① 具体应用场景 ② 遇到的问题及解决情况（已解决说明怎么解决 / 未解决说明试过哪些方案）③ AI 对用户请求的总结（类似求助帖）④ 帮助记录
- **再次单击同星 / 点「返回星空」**：回到全局视图
- **单击太阳**：查看原帖基准场景详情

## 运行

纯静态单文件，零外部依赖、无需后端。直接用浏览器打开 `index.html` 即可。
